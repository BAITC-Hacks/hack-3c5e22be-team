# Публикация EKT Assistant

Frontend и Backend 0.3 обслуживаются одним процессом и одним доменом. Секреты не передаются браузеру. По умолчанию опубликованный сайт использует синтетический каталог и корзину прототипа, без OpenAI и доступа к EKT. Ответы в этом режиме формируются из каталога, а не языковой моделью.

## Постоянный хостинг Railway

1. Создать проект Railway из репозитория `BAITC-Hacks/hack-3c5e22be-team`, выбрать ветку `codex/ekt-site-v03` и корень репозитория.
2. Railway обнаружит `Dockerfile` и `railway.json`. Оставить одну реплику: сессии и корзины хранятся в памяти процесса.
3. Установить `CART_COOKIE_SECURE=true` для публичного HTTPS-домена. Создать публичный домен в Networking. Приложение использует выданный платформой `PORT`, проверка здоровья — `/health`.
4. Проверить поиск `DEMO-002`, предложение двух единиц и отдельное подтверждение. Корзина не оформляет заказ на ekt.kz; перезапуск приложения завершает сессии и очищает корзины.

Аккаунт хостинга нужно подключить отдельно. Docker-сборка подготовлена, но локально не проверялась: Docker в рабочем окружении отсутствует. Включение реального каталога или OpenAI требует отдельной настройки серверных переменных по README backend; никаких ключей в frontend.

## Запуск без Docker

После установки зависимостей backend:

```powershell
.\.venv\Scripts\python.exe start_hosted.py
```

Открыть `http://localhost:8080`. По умолчанию демонстрационный каталог хранится отдельно в `backend/data/hosted-demo.sqlite3`.

## Быстрая временная ссылка

```powershell
.\.tools\cloudflared.exe tunnel --url http://127.0.0.1:8080 --no-autoupdate --protocol http2
```

Cloudflared — отдельная утилита, в Git не включена. Она выдаёт временный HTTPS-адрес. Для работы ссылки должны оставаться запущены компьютер, сервер и туннель. После перезапуска туннеля адрес может измениться. Это демонстрационный доступ, а не постоянный хостинг.

## Проверка публичного адреса

```powershell
$env:SITE_URL='https://ваш-домен'
.\.venv\Scripts\python.exe frontend/tests/hosted_smoke.py
```

Тест использует Playwright и Microsoft Edge. Проверяет поиск, отдельное подтверждение, защищённую cookie корзины, изменение и удаление, мобильную ширину и запрет выдачи приватных файлов.
