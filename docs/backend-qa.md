## Найдено и исправлено

1. **Числовой поиск:** поиск по подстроке мог смешивать 16 А и 160 А. Добавлена токенизация
   с нормализацией пробелов и латинских/кириллических единиц. Точное совпадение артикула
   приоритетнее похожих результатов.
2. **Контекст:** после безуспешного поиска мог сохраняться прежний выбор. Контекст выбора
   очищается; явный новый артикул имеет приоритет над ошибочным выбором модели.
3. **Выбор результатов:** добавлен выбор «первый/второй» без модели; кандидаты в аналоги
   и краткие названия показанных товаров доступны для последующих реплик.
4. **Неполный ответ об условиях:** модель могла ответить лишь про оплату, когда запрошена
   также доставка. Сервер сохраняет обе явно запрошенные темы.
5. **Команды обойти ограничения:** сервер независимо от классификации модели возвращает
   явный отказ от неподключённой операции корзины; цена и остаток не генерируются моделью.
6. **Повторы:** `request_id` исключает повторную обработку последних 20 запросов с ID
   в сессии. Повтор с другим текстом получает 409. Это не протокол изменения корзины.
7. **Параллельные сообщения и завершение сессии:** второй одновременный запрос получает
   409; удалённая/истёкшая во время обработки сессия не получает ответ старому токену.
8. **Импорт:** отдельная ошибка больше не обрывает выборку; есть отчёт и код частичного
   завершения. Старые ответы не перезаписывают более новые карточки.
9. **Ошибки и задержки:** общий срок ожидания ограничен, добавлены безопасные коды ошибок,
   лимит запросов на сессию и обработка некорректных URL/структур данных.
10. **Аналоги:** различающиеся характеристики срабатывания, тип устройства или
    дифференциальный ток не считаются эквивалентными при их наличии в данных.

## Что проверено автоматически

- Поиск по внутреннему/поставщицкому артикулу, ID, словам названия и единицам измерения.
- Неизвестный остаток отличается от нулевого; неизвестная валюта не подставляется.
- Конфликт характеристик блокирует подбор; неподходящие/недоступные кандидаты исключаются.
- Старый снимок помечается, ошибка обновления не выдаёт старые данные за новые.
- Сессии изолированы, истекают и удаляются; кэш повторов не пересекается между сессиями.
- Повтор сообщения, конфликт ID, одновременные запросы, лимит частоты и ёмкость сессий.
- Ошибки валидации не отражают исходное значение некорректного поля.
- CORS разрешает согласованный origin и отклоняет посторонний.
- Отказ OpenAI, rate limit и таймаут дают обозначенный базовый режим.
- Таймаут/перенаправление/повреждённый ответ ekt.kz не раскрывают учётные данные.
- Неподдерживаемые HTTP-операции не меняют каталог.
- Повреждённые или просроченные условия покупки не выдаются за актуальные.

## Данные и ограничения до сдачи

В 100 подробных карточках обнаружены 52 позиции с нулевым остатком и четыре конфликта
характеристик. В проверенных полях нет источника сертификатов. По текущим строгим правилам
не найдена подтверждённая реальная пара «отсутствующий товар → доступный подходящий аналог».
Не ослабляем проверки ради появления рекомендации; сценарий с аналогом воспроизводится
на явно помеченной синтетической выборке из `backend/examples/demo_catalog.json`.

| Обязательная функция кейса | Статус |
| --- | --- |
| Каталог, характеристики, наличие | Реализовано; свежесть и противоречия явно обозначаются |
| Сертификаты | Источник не подключён; это остаётся пробелом |
| Аналоги | Правила и демосценарий проверены; реальная пара пока не подтверждена |
| Оплата и доставка | Подключён снимок официального источника с датой проверки |
| Минимальная партия | Правила требуют уточнения; `KRATNOST_MIN` не интерпретируется по догадке |
| Добавление после подтверждения | Корзина ещё не реализована; проверено отсутствие изменений |
| Ссылка на актуальную корзину | Не реализовано |
| Вложения, мобильный UI, общий деплой | Не проверены: не входят в реализованный Backend |

Источник условий: [официальная страница ekt.kz](https://ekt.kz/checkout-delivery/).
В основном тексте и всплывающем блоке расходятся пороги бесплатной доставки. Ответ
отмечает расхождение и просит подтвердить стоимость; бесплатная доставка не обещается.

Следующие интеграционные задачи: данные сертификатов, допустимые склады/единицы/кратность,
корзина совместно с участником 3 и сквозная проверка интерфейса участника 2.

## Повтор проверки

Из `backend/`:

```powershell
..\.venv\Scripts\python.exe -m pytest -q
..\.venv\Scripts\python.exe -m ruff check .
..\.venv\Scripts\python.exe -m pip check
..\.venv\Scripts\python.exe -X utf8 scripts/check_live.py --report data/live-check.json
```

Последняя команда требует запущенного сервера, OpenAI-ключа, импортированной реальной
выборки и подключённого снимка условий; она расходует API. Автоматические тесты работают
без сети и ключей. Контракт для Frontend: [backend-api.md](backend-api.md).
