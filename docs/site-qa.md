# EKT Assistant: сайт по референсу + Backend 0.3

Проверено локально 23.09.2026. Backend: `538e89d36a1ed41a2a65c1bf76163cacaac8fc2d`.

## Визуальное сравнение

Основной и единственный визуальный референс — приложенный экран Script AI Chat.
Сохранены три колонки (275 px / гибкая / 275 px на широком экране), светлая левая
навигация, верхняя шапка, центральное приветствие, четыре карточки в сетке 2×2,
тонкие серые границы, мягкие скругления, нижний composer и пастельные акценты иконок.
После просмотра скриншотов уточнены размеры текста и предложений на мобильном экране.

Осознанные отличия:

- Правая колонка проектов заменена актуальной корзиной и недавно просмотренными товарами.
- Тексты, пункты навигации и знак заменены на EKT Assistant. Отдельные файлы логотипа,
  фото товаров и исходный шрифт не предоставлены; используются текстовый знак и локальные
  SVG. Изображения товаров берутся из поля `image`, если оно есть в API.
- Панель браузера Safari из иллюстрации не является частью сайта. Голос, вложения,
  подарки и платная подписка отсутствуют: для них нет подключённых функций проекта.
- На телефоне боковые колонки превращаются в раскрывающиеся панели. Доступна тёмная тема,
  но основной вариант соответствует светлому референсу.

## Проверки

| Область | Результат |
| --- | --- |
| Backend | 123 теста прошли; Ruff без замечаний |
| Поиск, карточки, контекст, аналоги и конфликт характеристик | Прошли через запущенный HTTP backend |
| Количество → предложение → подтверждение → корзина | Прошло; до кнопки корзина не изменяется |
| Предложение из чата «Добавь 2» | Показано, подтверждается отдельно |
| Изменение количества, удаление, отмена, очистка | Прошли, все изменения требуют подтверждения |
| Потеря ответа после успешного confirm | Повтор с тем же ключом не добавляет второй раз |
| Изменение цены в синтетической базе | Новое предложение; старая цена не применяется без согласия |
| Изменение остатка в синтетической базе | Новое предложение и повторное подтверждение |
| Прямая /cart | Открывается с cookie, содержит текущие позиции; чужая сессия получает 401 |
| Ошибка сети, ручной повтор, 409, завершение сессии | Отображаются и обрабатываются |
| Полная недоступность сервера | Ошибка и работающий повтор подключения |
| Загрузка | Индикатор и блокировка повторного нажатия |
| Ширины 320, 390, 768, 1024, 1600 px | Нет горизонтальной прокрутки страницы; отправка в зоне видимости |
| Высота 430 px при ширине 390 px | Имитирует уменьшение рабочей области клавиатурой; подтверждение доступно |
| Меню, помощь, примеры, переключение темы | Проверены в браузере |
| Секреты и вывод данных | Нет токена в localStorage/sessionStorage; строки выводятся как текст |

Браузер: установленный Microsoft Edge через Playwright. Скриншоты созданы в `test-results/`
и визуально просмотрены. Уменьшение viewport не заменяет проверку на физическом телефоне
с его экранной клавиатурой; доступ к такому устройству в этом прогоне отсутствовал.

Прогон использовал работающий сервер и синтетический каталог без внешних ключей.
OpenAI и реальные запросы EKT в этом прогоне не вызывались. Проверки реального каталога
участника 1 описаны отдельно в `backend-qa.md` и `cart-qa.md`.

Сертификаты и вложения не подключены. Корзина не оформляет заказ, не резервирует товар
и не переносится на ekt.kz. Денежные строки сохраняются без округления на фронтенде.

Инструкции воспроизведения: `frontend/README.md`. Одна команда после установки: `python run_demo.py`.
