# Матрица пяти приёмочных проверок

Статус всех бизнес-проверок: **не реализованы**. Правила ниже предложены для согласования; инфраструктурный smoke-тест не засчитывается как их прохождение.

| № | Сценарий и данные | Ожидаемый результат |
| --- | --- | --- |
| 1 | Запрос существующего артикула A с известными характеристиками, остатками по складам и сертификатом; повтор для товара без сертификата | Данные совпадают с источником, есть единицы измерения; ссылка открывает сертификат A. Отсутствующий документ не выдумывается. |
| 2 | A отсутствует; B в наличии и соответствует обязательным параметрам категории; отдельный случай без подходящих аналогов | Минимум один релевантный доступный аналог, когда он есть; объяснены совпадения и отличия. Если аналогов нет — честное сообщение. Корзина не меняется. |
| 3 | Вопросы об оплате, доставке и минимальной партии на утверждённых тестовых правилах, включая исключение для артикула | Ответ соответствует источнику и содержит ссылку. Город, тип клиента и иные необходимые условия уточняются. При недоступности источника — сообщение об ограничении. |
| 4 | Остаток A=5, в корзине 2, предложение добавить 3: без подтверждения, после подтверждения, повтор подтверждения; попытка добавить 4; изменение остатка/цены до записи | Без подтверждения изменений нет. После подтверждения итог 5. Повтор не дублирует запись. Превышение остатка блокируется; изменённые условия требуют нового подтверждения. |
| 5 | После добавления открыть ссылку в текущей сессии на десктопе/мобильном; обновить страницу; открыть из другой сессии | Актуальный состав и количество сохраняются. Ссылка ведёт в корзину текущего клиента; другая сессия не получает чужую корзину. |

Для каждой проверки сохранять обезличенные запрос/ответ, версию источника, корзину до/после, результат и дату. До интеграции тесты выполняются на фиксированных синтетических данных, затем повторяются с тестовым API партнёра.

Дополнительно согласовать: порог времени ответа и нагрузку; отдельный лимит для вложений; обязательные параметры аналогов для каждой категории; транзакционность набора позиций и правила резервирования.
