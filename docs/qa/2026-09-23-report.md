## Браузерная проверка

- Frontend показал «Сервер подключён · 3 товаров»: соединение и CORS реально работают.
- Пройдены поиск DEMO-002 и объяснимый аналог для DEMO-001; сведения совпали с fixture.
- M3 и M4 воспроизведены в UI: честные сообщения об отсутствии интеграции, без ложного успеха.
- При ширине 390×844: `scrollWidth=375`, `innerWidth=390`, горизонтального переполнения нет;
  кнопка «Новый диалог» доступна. Это ограниченная проверка одного мобильного размера,
  не полная проверка всех устройств или accessibility.
- Backend остановлен: интерфейс показал «Нет связи с сервером» и «Повторить».
- После перезапуска повтор вернул «Сессия завершена», автоматического продолжения не произошло.
- «Новый диалог» восстановил работу; новый DEMO-002 успешно отображён.
- Прямая попытка открыть `/cart` в браузере QA была остановлена браузером
  `ERR_BLOCKED_BY_CLIENT`; её не засчитываем как проверку отображения корзины.
  Изоляция и актуальность HTML `/cart` подтверждены HTTP-тестами, не этим переходом.
- Playwright-скрипт из ветки frontend в этом прогоне не запускался; сценарии выше выполнены
  через браузерные инструменты. Проверка HTTP-ошибок не заменяет его полный набор.

## Ограничения и решение о готовности

Нет проверки настоящего магазина, реальной записи корзины, реального AI, сертификата с
подтверждённым источником, оформленного заказа, внешнего хостинга и нагрузочного SLA.
Данные синтетические, в память сервера не загружались клиентские документы/платёжные данные.
Выполнение «за единицы секунд» на реальном AI не измерено и не заявляется.

GitHub Actions для корзины по-прежнему `failure` до шагов, список шагов пуст:
[run 35851753746](https://github.com/BAITC-Hacks/hack-3c5e22be-team/actions/runs/35851753746).
Причина недоступна через коннектор; это не доказательство ошибки тестов. Отдельно QA-007.

Для полного демо сначала закрыть QA-001/002/003/005/006. Для проверяемой сборки команды
нужно также QA-007. QA-004 — ошибка устойчивости P2, не причина блокировки обычного happy path.
Реестр: [blockers.md](blockers.md). Изменения продукта и слияние веток этим прогоном не выполнялись.
